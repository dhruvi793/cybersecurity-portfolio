# PHISH-001: Simulated Phishing Incident Response Investigation

## Overview
A controlled phishing incident response investigation performed in an isolated Kali Linux training environment.

## Tools Used
- Kali Linux
- Wireshark
- tcpdump
- tshark
- sha256sum
- exiftool

## Skills Demonstrated
- Phishing email analysis
- Email header investigation
- URL and DNS analysis
- Attachment analysis
- Network traffic analysis
- IOC extraction
- MITRE ATT&CK mapping
- Incident response planning
