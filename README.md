# PHISH-001: Simulated Phishing Incident Response Investigation

## Overview

This project demonstrates a controlled phishing incident response investigation performed in an isolated Kali Linux cybersecurity training environment.

The investigation covered email analysis, URL investigation, attachment analysis, network traffic analysis, IOC extraction, and incident response planning.

## Objectives

- Analyze simulated phishing email headers
- Assess SPF, DKIM, and DMARC authentication
- Investigate suspicious URLs and DNS information
- Analyze a benign email attachment
- Calculate SHA-256 file hashes
- Capture and analyze network traffic
- Extract and document Indicators of Compromise (IOCs)
- Map observed activity to MITRE ATT&CK
- Develop incident response recommendations

## Tools Used

- Kali Linux
- tcpdump
- tshark
- Wireshark
- sha256sum
- exiftool
- file
- strings

## Investigation Workflow

1. Simulated phishing email creation
2. Email header analysis
3. SPF/DKIM/DMARC assessment
4. URL and DNS investigation
5. Attachment analysis and hashing
6. Network traffic capture
7. PCAP analysis
8. IOC extraction and enrichment
9. MITRE ATT&CK mapping
10. Incident response planning

## Key Findings

- Identified simulated phishing email indicators
- Investigated a laboratory-only URL
- Analyzed a benign training attachment
- Captured controlled HTTP traffic
- Documented IOCs and incident response recommendations
